AI Toolkit portable - LoRA MiniMax-H3-Image - SANS Node.js ni npm
Cible : Windows 10/11, RTX 3090 24 Go, 64 Go RAM
=============================================================================

EMPLACEMENT
  Dezippez dans un chemin SANS espaces, sur un SSD, avec 80 Go libres minimum.
  Exemple : D:\AI\H3-LoRA\

ORDRE D'UTILISATION
  1_INSTALLER.bat          Une seule fois (10 a 30 min). MinGit, uv, Python
                           3.12, torch, FFmpeg... tout dans ce dossier.
                           Rien n'est installe sur le systeme, et ni Node.js
                           ni npm ne sont installes ni utilises.
  2_LANCER_UI.bat          Ouvre l'UI Python (Gradio) : http://127.0.0.1:7860
  3_METTRE_A_JOUR.bat      git pull + resynchronisation des dependances
  4_TELECHARGER_MODELE.bat Optionnel : pre-telecharge les poids (aussi faisable
                           dans l'onglet "Modeles" de l'UI)
  2_LANCER_UI_ADMIN.bat    Facultatif : meme UI avec les droits administrateur,
                           pour changer la limite de puissance du GPU sans
                           fenetre de confirmation Windows.
  DIAGNOSTIC.bat           En cas de souci : GPU, torch, test int8, gradio

PROGRESSION ET REPRISE DES TELECHARGEMENTS
  - MinGit (empreinte SHA-256 verifiee) / uv : barre de progression curl ; un fichier .part est repris
    la ou il s'est arrete (repli automatique sur BITS si curl echoue).
  - Depot git : progression affichee ; un clonage interrompu est repris.
  - Python, torch, dependances : progression affichee par uv ; ce qui est
    deja telecharge reste dans cache\uv.
  - Poids du modele (~30 Go) : une barre par fichier (taille, debit, temps
    restant), 5 tentatives automatiques ; un fichier .incomplete est repris.
  - Dans tous les cas : en cas de coupure, fermeture ou reboot, RELANCEZ le
    meme script. Les etapes finies sont sautees, le reste reprend.

CE QUI RESTE OU
  ai-toolkit\   le depot ostris (code, .venv, .uv, .mingit, .ffmpeg)
  models\       poids MiniMax-H3-Image (MODELS_PATH)
  datasets\     vos jeux d'images
  output\       LoRA entraines, apercus, journal_ui.txt par job
  configs\      YAML generes par l'UI
  cache\        caches Hugging Face, triton, uv
  Pour deplacer l'installation : deplacez tout le dossier, supprimez
  ai-toolkit\.venv puis relancez 1_INSTALLER.bat (le venv contient des
  chemins absolus ; les modeles et le cache uv evitent de tout retelecharger).

L'UI (onglets)
  1. Dataset        dossier, ajout d'images, verification des legendes,
                    LEGENDAGE AUTOMATIQUE (Qwen3-VL) des images sans .txt.
  2. Entrainement   reglages avec aide et valeurs preconisees ;
                    TEST RAPIDE (20 pas) : mesure vitesse et memoire, propose
                    les reglages et une duree ; reglages enregistres par job ;
                    file d'attente ; pause automatique a un pas ou une heure.
  3. Resultats      apercus, COURBE DE PERTE, checkpoints, copie vers ComfyUI.
                    Mise a jour automatique toutes les 5 s.
  4. Tester un LoRA memes prompts et meme graine sur plusieurs checkpoints,
                    pour choisir le meilleur (experimental).
  Modeles           pre-telechargement + etat des fichiers.
  Outils            notifications (son, telephone via ntfy.sh), anti-veille,
                    dossier ComfyUI, figer / defiger la version d'ai-toolkit.
  En haut : phase, barre des pas (ETA, s/it), barre de l'etape en cours,
  moniteur VRAM / RAM / temperature GPU, journal en direct, et les boutons
  Pause, Apercu maintenant, Arreter.

PROCEDES D'ENTRAINEMENT (onglet Entrainement)
  Choisir un procede remplit les champs ; tout reste modifiable ensuite.
  - Standard ai-toolkit : vos reglages, inchanges.
  - Rapide 512 : resolution 512, rang 32, optimiseur automagic4 (taux
    auto-regle, depart et plafond 2,5e-4), EMA 0,98, 30 passages sur le
    dataset. Ce sont les reglages que Fizgig a retenus pour H3-Image apres
    de nombreux essais ; ici avec les composants d'ai-toolkit.
  - Recette Fizgig complete (experimental) : la meme, plus
      . l'adaptateur d'entrainement de Fizgig, telecharge puis converti au
        format d'ai-toolkit au premier job ;
      . l'optimisation de ressemblance : le niveau de bruit le plus net est
        tire plus souvent (17, 33, 50 % aux passages 1, 3, 5 ; 75 % aux
        passages 2, 4, 6 et ensuite) ;
      . des apercus en LCM au lieu d'Euler.
  Ces trois derniers points ajustent ai-toolkit en memoire, sans modifier
  ses fichiers. Si son code a change, l'ajustement s'abstient et l'ecrit
  dans le journal (lignes [H3-UI]). Au premier job avec l'adaptateur Fizgig,
  verifiez dans le journal "Adaptateur Fizgig converti : 200 modules".
  Changez de nom de job quand vous changez de procede ou d'adaptateur.
  Garde-fou RAM : un avertissement s'affiche au lancement et pendant le job
  si la RAM manque (sous Windows la memoire de la carte en depend).

LEGENDES : LA REGLE QUI COMPTE LE PLUS
  Decrire ce qui varie, taire ce qui est permanent. Ce qui est decrit
  s'attache aux mots de la legende ; ce qui est tu s'attache au mot
  declencheur.
  - Personnage : ni cheveux, ni barbe, ni carrure, ni cicatrices dans les
    legendes. Cadrage, angle, pose, tenue, fond, eclairage seulement.
  - Style : l'inverse, tout le contenu mais pas le style.
  - Mot declencheur invente avec des chiffres (m41ne), jamais un vrai mot.
  - Une image = un sujet, une vue : decoupez les planches multi-vues.
  Dans l'onglet Dataset : choisissez le "Type de LoRA" avant le legendage
  automatique (la consigne s'adapte), puis "Analyser le dossier" liste les
  legendes qui decrivent des traits permanents ou plusieurs vues.

ROGNER LES FILIGRANES ET TEXTES (onglet Dataset)
  Un detecteur de texte repere filigranes, signatures, adresses de site et
  legendes, puis propose pour chaque image le plus grand cadrage qui n'en
  contient aucune. L'image est seulement rognee, rien n'est repeint.
  - "Analyser les images" : vignettes avec le texte en rouge, le cadrage
    propose en vert, la zone retiree assombrie.
  - Decochez les images ou le texte fait partie de la scene, puis "Rogner".
  - Originaux copies dans <dataset>_originaux, A COTE du dataset (ai-toolkit
    lit les sous-dossiers) ; "Restaurer tous les originaux" les remet.
  - Une image dont le texte est trop central est declaree non rognable.
  - Non detectes : logos sans texte, filigranes repetes sur toute l'image.
  Le detecteur (PP-OCRv3, 2,4 Mo) est telecharge au premier usage dans
  models\outils ; sans reseau, un detecteur de secours moins fiable sert.

DEMARCHE CONSEILLEE
  1. Dataset + legendes (automatiques puis relues).
  2. Test rapide, et appliquer ses recommandations.
  3. Entrainement (la nuit : le PC ne se met pas en veille pendant un job).
  4. Tester un LoRA sur 2 a 4 checkpoints, copier le meilleur dans ComfyUI.
  5. Figer la version d'ai-toolkit une fois que tout fonctionne.

PRESETS 3090
  int8 + offload (defaut)  transformer int8, 35 % des couches en RAM.
                           C'est le reglage par defaut d'ai-toolkit pour ce
                           modele et le calcul int8 est natif sur la 3090.
  w4a8 (EXPERIMENTAL)      transformer 4 bits, plus leger et sans offload,
                           donc potentiellement plus rapide.
                           Risque lu dans le code : son noyau triton utilise
                           un type FP8 que le depot indique non compilable
                           avant les RTX 40. La case "Correctif w4a8" (cochee
                           par defaut) force alors la decompression en torch
                           pur, sans toucher au code d'ai-toolkit. Ni le
                           risque ni le correctif n'ont ete verifies sur une
                           vraie 3090 : validez avec le Test rapide.
  Les memes reglages existent en YAML dans presets\ (ligne de commande).

PAUSE, ARRET ET REPRISE D'UN ENTRAINEMENT
  - "Pause (sauvegarder l'etat)" : a la fin du pas en cours, ai-toolkit
    ecrit un checkpoint (LoRA + optimiseur + numero de pas), puis s'arrete
    proprement. Au plus un ou deux pas sont refaits a la reprise. La VRAM
    est liberee pendant la pause.
  - Reprendre : meme nom de job, bouton "Lancer / Reprendre". Le modele est
    recharge (quelques minutes), les caches latents/texte sont reutilises.
    Marche aussi apres fermeture de l'UI ou redemarrage du PC.
  - "Arreter sans sauvegarder" : arret propre, reprise au dernier checkpoint
    automatique (tous les N pas).
  - "Apercu maintenant" : genere les apercus a la fin du pas en cours.
  - Onglet Resultats : apercus et checkpoints du job selectionne se mettent
    a jour tout seuls (5 s) ; le job lance y est selectionne d'office.
  - Fermer la fenetre noire coupe net : un checkpoint en cours d'ecriture
    peut etre tronque. A la reprise, l'UI renomme les fichiers tronques en
    .corrompu et repart du checkpoint valide precedent.
  Technique : l'UI pilote ai-toolkit par son mecanisme natif (table SQLite
  h3_ui.db : save_now / sample_now / stop), celui de son UI officielle.

TEMPERATURE ET PUISSANCE DU GPU (onglet Outils)
  - Alerte (85 C par defaut) : notification, temperature affichee en rouge.
  - Pause automatique (91 C par defaut, pendant 60 s) : pause avec
    sauvegarde. Filet de securite, pas une regulation.
  - Limite de puissance en watts (0 = inchangee) : baisse la chauffe pour
    une perte de vitesse en general faible. "Enregistrer" l'applique tout de
    suite si un job tourne (sans l'interrompre), sinon au prochain lancement.
    "Appliquer maintenant" et "Retablir la limite d'origine" agissent a tout
    moment. Sans droits administrateur, Windows demande une confirmation a
    chaque changement, les jobs de la file d'attente ne modifient pas la
    limite, et elle reste en place apres le job.
  - Thermostat (case a cocher) : toutes les 45 s pendant un job, compare
    la temperature moyenne a la cible (72 C conseille). Trop chaud : baisse
    la limite de 10 a 30 W. Plus de 3 C en dessous : la remonte de 10 W.
    Plancher reglable (150 W), plafond = la limite de puissance saisie, ou
    celle d'origine si 0. Demande 2_LANCER_UI_ADMIN.bat. L'etat et les
    derniers ajustements s'affichent dans l'onglet Outils et le bandeau.
    "Plancher atteint" signifie que la ventilation ne suffit pas.
  - Les ventilateurs ne sont PAS pilotes par l'UI : reglez une courbe dans
    MSI Afterburner ou FanControl.
  - Le moniteur affiche aussi la vitesse du ventilateur et la puissance.

VERSION D'AI-TOOLKIT
  Par defaut : derniere version de la branche main. Ce paquet a ete audite

LIMITES CONNUES (non verifie sur une vraie 3090)
  - Consommation VRAM, vitesse et tailles exactes des fichiers : estimations.
  - Tester un LoRA : repose sur un job ai-toolkit a 0 pas d'entrainement,
    comportement non verifie sur le vrai outil.
  - Legendage automatique : modele telecharge au premier usage (10 a 20 Go).
  - Apercus en 2048x2048 : le decodage peut depasser 24 Go ; baissez a 1536.
  - Entrainer en 1024/1536 est un compromis memoire : le modele vise 4 MP+.
  - Licence des poids MiniMax-H3-Image : a lire sur la page Hugging Face
    avant tout usage commercial ; non verifiee ici.

SPECIFICITES DU MODELE (a ne pas modifier)
  - Distille 6 pas sans CFG : sample_steps 6, guidance_scale 1.
  - Entrainement avec l'adaptateur ostris (assistant LoRA) actif ; il est
    coupe automatiquement pour les apercus.
  - Pense pour 4 a 20 MP en sortie : des apercus en 1024 montrent plus
    d'artefacts, c'est normal. Par defaut l'UI echantillonne en 2048.
  - Avec un dossier d'images de reference, il apprend en mode edition
    (references appelees <Picture 1>, <Picture 2>... dans le prompt).

RTX 3090 (Ampere) - CE QU'IL FAUT SAVOIR
  - int8 (convrot8 / w4a8) : matmul int8 natif, OK.
  - Encodeur de texte NVFP4 : pas de FP4 materiel sur Ampere, il est
    decompresse a la volee. Ca marche, juste plus lentement ; et comme les
    embeddings sont mis en cache, il ne sert qu'au debut.
  - Les noyaux triton FP8 rapides demandent Ada+ : repli torch automatique.

SI CA PLANTE EN MEMOIRE (CUDA out of memory)
  Dans l'ordre :
  1. resolutions : 1024 seule
  2. apercus en 1536, ou "Desactiver les apercus"
  3. curseur "Part du transformer en RAM" : 0.35 -> 0.5 -> 0.7
     - vos 64 Go de RAM encaissent largement
  4. essayer le preset w4a8 (voir l'avertissement plus haut)
  5. rang LoRA 16 -> 8
  Fermez navigateur lourd et jeux : Windows reserve deja ~1 Go de VRAM.
  Fichier d'echange Windows : laissez-le "gere par le systeme" (pic de RAM au
  chargement des ~30 Go de poids).
